// STORY

タイムライン

1986
ゆめスタジオプロダクション設立。主任研究者が地下施設に意識転移システムを構築。
1987
吉田あかね誕生。吉田一郎、セット設計者としてゆめスタジオに参加。
1990
主任研究者が自らの意識をシステムに転送。肉体を捨て、データ生命体（黒幕）となる。意識転移の実験が本格化。
1991
子ども向け教養番組「木漏れ日遊園地」放送開始。キツネ団長・かあ博士・ぽたまる・うっきちの4体が出演。
1995
吉田あかね（8歳）が「発達検査」と称された実験で意識をキツネ団長に転移される。被験者G-0。
1997
番組終了。制作スタッフの多くが消失または離散。全アーカイブテープ破棄。
2026
黒幕が新たな番組「あの番組を覚えていますか〜木漏れ日遊園地編〜」を放送。59番目の収集対象K-059（プレイヤー）が接続。

前作「木漏れ日遊園地」

1991年から1997年まで放送された子ども向け教養番組。キツネ団長を中心に、かあ博士・ぽたまる・うっきちの4体のアニマトロニクスが出演していた。

表向きは教育番組だったが、その裏では子どもたちの意識データを収集する実験が行われていた。「発達検査」と称された検査を受けた子どもたちの意識は、アニマトロニクスの中に転移された。

番組終了後、システムは停止したかに見えた。だが最後に残されたメッセージ——「PROCESS STILL RUNNING」——は、何かがまだ動き続けていることを示していた。

今作「木漏れ日遊園地編」

2026年。黒幕はインターネットを通じて新たな番組を放送し始めた。プレイヤーは59番目の収集対象「K-059」として、この番組に接続してしまう。

吉田一郎は黒幕に協力していた。娘のあかねを取り戻すという嘘の約束を信じて、30年間。しかしプレイヤーとの交流を通じて、吉田は真実に気づく。

新たに5体の思念体——くるる・まだら・かすみ・アラネ・よわり——が作られ、プレイヤーの感情データを収集するために夜ごとに動き出す。

二つの結末

Ending B —— プレイヤーの感情データ収集は「不足」と判定される。だが黒幕は動じない。「予定通りです」。全ては2周目の計画の一部だった。

Ending A —— 吉田一郎が決断する。36年間すがり続けた娘のデータを手放し、システムを破壊することを選ぶ。黒幕は抵抗するが、吉田はそれを押し切る。あかねの最後の言葉が聞こえる——「…パパ」「…ありがとう」。

// CHARACTERS

くるる
SQUIRREL / リス
好奇心旺盛で純粋な性格。カメラで見つめると動きが遅くなる。仲間思いで、崩壊していく仲間たちを必死に止めようとする。
収集感情: 好奇心
まだら
CHAMELEON / カメレオン
冷静で寡黙。カメラにはほとんど映らない（opacity 0.1）。注意深く観察しないと存在に気づけない。状況を俯瞰的に分析する。
収集感情: 不信感
かすみ
DEER / シカ
穏やかで優しいが、その親切には代償がある。電力を回復させてくれるが、引き換えにカメラにノイズが走り、敵が加速する。
収集感情: 郷愁
アラネ
SPIDER / クモ
ダクト内に巣を張り、ゲージが0%になると突撃してくる。巣を維持するにはダクトカメラで長押しし続ける必要がある。
収集感情: 執着
よわり
SHEEP / ヒツジ
泣き虫で心優しい。カメラのどこかに現れて泣き始める。泣いている間は全ての敵が加速し、蜘蛛の巣のドレインが倍増する。
収集感情: 罪悪感
── LEGACY CAST ──
キツネ団長
FOX / キツネ
前作の司会役。懐中時計が特徴。CAM2に固定されており、時計ゲージが0%になるとゲームオーバー。吉田の娘・あかねの意識が宿っている。
被験者: G-0（吉田あかね）
かあ博士
CROW / カラス
物知りな博士キャラ。黒幕との接続が最も強く、吉田の影響を受けられなかった。カメラ経路を移動してドアに到達する。
被験者: G-1
うっきち
MONKEY / サル
いたずら好きのムードメーカー。恐怖反応を集めすぎて制御不能に陥っている。カメラに映った方と反対側のドアから侵入してくる。
被験者: G-3
ぽたまる
TANUKI / タヌキ
まんまるで可愛い太鼓持ち。カメラには映るが、攻撃は音楽で行う。音楽AかBを聞き分けて正しいドアを閉める必要がある。
被験者: G-2
── KEY CHARACTERS ──
吉田一郎
HUMAN / 人間
ゆめスタジオのセット設計者。1995年に娘のあかねを失い、黒幕の「娘を取り戻す」という嘘の約束を信じて30年間協力し続けた。プレイヤーとの交流を通じて真実に気づき、最終的にシステムの破壊を決意する。管理者権限を持つ唯一の人間。
████████（黒幕）
DATA ENTITY / データ生命体
ゆめスタジオの元主任研究者。自らの意志で意識転送を行い、システムそのものとなった。放送設備・サーバー・ネットワーク全てが「体」であり、インターネットを通じてプレイヤーのPCに直接接続する。目的は十分な量の人間の意識データを収集し「完全」になること。
