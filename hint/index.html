Night 1 [ + ]
メールを確認してみよう。最初に届いてるメッセージに手がかりがある。
「…離さないで…あの名前を…」。名前を離さない、つまり——長押し。
特番サイトのスタッフページを開いてみよう。誰か一人だけ、他と違うところがある。
スタッフページの「吉田一郎」を10秒間長押しする。画面がじわじわ暗くなっていけば正解。途中で離すと戻ってしまう。
Night 2 [ + ]
Night1クリア後のメールを読もう。「…間違ってる…ところがある…ひとつじゃない…」
サイトの中に「間違い」が3つ隠されている。キャラ紹介ページや番組概要ページをよく読んで、おかしいところを探してクリックしよう。
ヒント：コーナー名をよく見て。キツネ団長の担当コーナーは本当に正しい？ぽたまるの「ソング」って合ってる？番組の放送曜日は？
3つの間違いをクリック：
1. キツネ団長のページ：「なぜなぜ教室」→ 正しくは「冒険タイム」
2. ぽたまるのページ：「ぽたまるソング♪」→ 正しくは「ぽたまるダンス♪」
3. 番組概要ページ：「毎週日曜日」→ 正しくは「毎週土曜日」
3つ修正後にお問い合わせページを開くと、Night2への入口が出現する。
Night 3 [ + ]
Night2クリア後のメールを確認しよう。「クイズの準備ができたよ！」という招待が届いているはず。
デスクトップにチャットアイコンが追加されている。キツネ団長とチャットで会話して、クイズに挑戦しよう。
クイズの答えは全てサイト内に書かれている。スタッフ情報、番組構成、キャラクター情報をよく読み返してみよう。
チャットでクイズ3問に正解する：
Q1「辞めた脚本家の名前」→ 渡辺千春
Q2「コーナー間に隠されていたもの」→ ブリッジ映像
Q3「消えた5番目のキャラ」→ ひかりちゃん
Night 4 [ + ]
Night3クリア後、デスクトップに新しいアイコンが出現しているはず。「旧サイト（アーカイブ）」を開いてみよう。
旧サイト（前作のアーカイブ）と今のサイトを見比べてみよう。黒幕が書き換えた箇所が3つある。
見つけた差分をPopinのDMで「ゆうやけさんぽ」に報告しよう。キーワードを入力すると反応がある。
3つの差分をDMで報告：
1. スタッフ一覧の「人形デザイン」の行が削除されている
2. 試作キツネの説明が「保管」→「廃棄処分」に書き換え
3. 設立年が「1987年」→「1988年」に変更
DMで「試作きつね」「人形デザイン」「1987」などのキーワードを送る。
Night 5 [ + ]
Night4クリア後、PopinのDMに新しい会話が解放されている。ゆうやけさんぽと話を進めよう。
DMの会話を最後まで進めると、何かが起きる。選択肢を全て選んでいこう。
DM Phase2のウォームアップ会話を最後まで進める。会話が崩壊し始め、自動的にNight5へ遷移する。
