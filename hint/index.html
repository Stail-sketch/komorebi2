行き詰まった時のヒント集
Night 1 [ + ]
メールを確認してみよう。最初に届いてるメッセージに手がかりがある。
「…離さないで…あの名前を…」。名前を離さない、つまり——長押し。
特番サイトのスタッフページを開いてみよう。誰か一人だけ、他と違うところがある。
スタッフページの「吉田一郎」を10秒間長押しする。画面がじわじわ暗くなっていけば正解。途中で離すと戻ってしまう。
Night 2 [ + ]
Night1クリア後のメールを読もう。「…情報が…書き換えられてる…3つ…正しくないところがある…触れてみて…」
サイトの中に「間違い」が3つ隠されている。キャラ紹介ページや番組概要ページをよく読んで、おかしいテキストを見つけたら直接クリックしよう。
コーナー名をよく見て。キツネ団長の担当コーナーは本当に正しい？ぽたまるの「ソング」って合ってる？番組の放送曜日は？
間違いテキストを直接クリックすると、グリッチしながら正しい内容に修正される：
1. キツネ団長のページ：「なぜなぜ教室」→ 正しくは「冒険タイム」
2. ぽたまるのページ：「ぽたまるソング♪」→ 正しくは「ぽたまるダンス♪」
3. 番組概要ページ：「毎週日曜日」→ 正しくは「毎週土曜日」
3つ目を修正した瞬間、画面にバグ文字が溢れ出し、Night2へ自動遷移する。
Night 3 [ + ]
Night2クリア後のメールを確認しよう。添付ファイルをクリックするとチャットが解放される。
キツネ団長とのチャットでは、サイトの内容を読んだか聞かれる。「読んだ」と答えるとクイズが始まる。答えは全てサイト内のページに書いてある。
全部で5問。視聴率データ、不思議な放送日、アニマトロニクスの改修記録、VHSの映像、そして社長がよく使っていた言葉。番組調査レポートと関係者証言をよく読もう。
チャットで5問のクイズに全問正解する：
Q1「番組で一番視聴率が高かった回って何%？」→「9.1」
Q2「視聴率0%が記録された日は何月何日？」→「11月13日」
Q3「1996年改修の技術者は何日間泊まり込み？」→「3」
Q4「よわりが見つけたVHSのタイムスタンプは？」→「2時34分」
Q5「制作会社の社長がよく使ってた言葉は？」→「理想の子ども」
全問正解後、キツネ団長がNight3への入口を教えてくれる。
Night 4 [ + ]
Night3クリア後、チャットでキツネ団長がある企業サイトのことを教えてくれる。「ゆめスタジオプロダクションのサイトがまだ残ってるみたい」。
企業サイトの社員専用ページにログインフォームがある。パスコードは6桁の数字。ヒントは「各文書の管理番号を参照してください」。
ゆめスタジオのサイト内に散らばっている文書には全て管理番号「YSP-XXXX-XX」がついている。黒塗り部分（█）が文書ごとに違う。9つの文書の番号を見比べて、6桁の数字を特定しよう。
ゆめスタジオ社員専用ページ（yumestudio/staff.html）で「199703」を入力する。
9つの文書の管理番号YSP-XXXX-XXの黒塗り部分は文書ごとに異なる。各文書は1〜2桁だけ見えており、全文書を照合すると6桁すべてが特定できる：1-9-9-7-0-3。入力成功でNight4に直接遷移。
Night 5 [ + ]
Night4でコードを入力した場所を覚えてる？クリア後、あのページが変化しているはず。もう一度見に行ってみよう。
社員専用ポータルの「技術部専用」セクションに、まだ稼働中のシステムがある。そこからシステム端末にアクセスできる。各レベルの最深部にパスコード入力欄があり、ヒントはそのレベルのファイル内に隠されている。Level5まで到達すると何かが起きる。
各レベルのヒント：
L1→L2：Level1のファイル内に散りばめられた数字を探そう
L2→L3：Level2のファイル内にコードが書かれている
L3→L4：トレースログに注目。ある重要な起動日
L4→L5：K-059の収集率に関係する数字
システム端末のパスコード：
L1→L2：「2847」
L2→L3：「GX07」
L3→L4：「1128」（ysp-core-01起動日=11月28日）
L4→L5：「0873」（K-059の収集率87.3%）
Level5到達でCOREプロセスの正体が明かされ、Night5へ遷移する。
Night 6（EndB後） [ + ]
Night5をクリアするとEndBが再生される。EndBの後、デスクトップに戻されたら——まだ終わっていない。メールを確認しよう。
EndB後に解放される吉田の調査ファイル（全15通）を全て読もう。メール経由でアクセスできる。全て読了するとNight6への道が開く。
Night6の解放には3つの条件が必要：
1. Night5クリア済み
2. EndB視聴済み
3. 吉田ファイル全15通読了済み
全て満たすとデスクトップにNight6のアイコンが出現する。
FNaFパート（ゲームプレイ） [ + ]
カメラ（数字キーorクリック）で部屋を監視。左右ドアの開閉で侵入を防ぐ。
全ての操作は電力を消費する。電力が0%になるとゲームオーバー。
カメラOFFの時間を意識しよう——カメラを使わないことも電力節約になる。
カメラで見つめると移動速度が低下する。定期的にカメラで位置を確認しよう。
カメラにほとんど映らない（透明度が非常に高い）。画面を注意深く見ないと存在に気づけない。
電力を回復してくれるが、引き換えに敵の移動速度が上がる。電力が余裕のある時は受け取らない方がいい場合もある。
ダクトカメラ（Wキー）で巣ゲージを維持する。ゲージが0%になると突撃してくる。他の操作と並行して定期的にダクトを確認しよう。
カメラのどこかに現れて泣き始める。泣いている間は全敵が加速し、蜘蛛の巣ドレインも倍増する。すぐに見つけて対処しよう。
何度もゲームオーバーになると、少しずつゲームが簡単になっていく。電力の減りが遅くなり、敵の動きも穏やかになる。諦めずに挑戦し続けよう。
