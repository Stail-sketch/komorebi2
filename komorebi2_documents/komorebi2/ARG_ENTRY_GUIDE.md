## 全体の流れ

```
PCデスクトップ（index.html）
  ├── ブラウザ → 特番サイト（official/）
  ├── Popin → 架空SNS + DM（twitter/）
  ├── メール → 受信ボックス（mail/）
  ├── チャット → キツネ団長チャット（chat/）※Night2クリア後に解放
  └── 旧サイト → 前作アーカイブ（archive/）※Night3クリア後に出現
```

## Night1への入口

**場所**：特番サイト → スタッフページ（official/staff.html）

**仕掛け**：「吉田一郎」の名前を10秒間長押し

**プレイヤーが気づくための違和感**：
- 吉田一郎だけフォントの太さが微妙に太い（font-weight: 700 vs 他の通常）

**長押し中の演出**：
- 画面全体がじわじわ暗くなる（10秒かけてフェードtoブラック）
- 10秒で完全暗転 → Night1へ遷移
- 途中で離すと暗転がスッと元に戻る

**ヒント**：
- メール初期メッセージ「…離さないで…あの名前を…」

## Night2への入口

**方式**：サイト内の「間違い」を3つ見つけてクリック → contact.htmlが変異

**場所**：official/character_kitsune.html, tips.html, character_potamaru.html → contact.html

**仕掛け**：サイト内に意図的に仕込まれた3つの誤りを見つけてクリックする。クリックすると間違い箇所がグリッチ演出で正しい値に修正される。3つ全て修正した状態でcontact.htmlを開くと画面全体が変異してNight2への入口が出現する。

**3つの間違い**：

1. **character_kitsune.html — 担当コーナーが別キャラのものになっている**
   - 「**キツネ団長のなぜなぜ教室**」→ 正しくは「**キツネ団長の冒険タイム**」
   - なぜなぜ教室はかあ博士のコーナー。キャラページを読んでいれば気づく

2. **character_potamaru.html — コーナー名が間違っている**
   - 「**ぽたまるソング♪**」→ 正しくは「**ぽたまるダンス♪**」
   - 口癖に「いっしょにおどろう！」と書いてあるのにソングは矛盾

3. **about_program.html — 放送曜日が間違っている**
   - 「毎週**日曜日**に放送」→ 正しくは「毎週**土曜日**」
   - basic.htmlなど他のページでは「毎週土曜日 8:30〜9:00」と書いてある

**クリック時の演出**：
- テキストがグリッチ（ランダム文字に化ける）
- 0.5秒ほどで正しい値に修正される
- 修正後に緑色で一瞬光る

**3つ修正後にcontact.htmlへ**：
- ページ全体が暗転・ぼやける
- 黒画面にシステムログがタイプライター表示
  - `[SYSTEM] site_integrity_check: 3 errors corrected`
  - `[SYSTEM] unauthorized_modification detected`
  - `…見つけてくれたんだ`
  - `…ありがとう`
- 画面シェイク+フリッカー
- `▶ proceed` → Night2へ遷移

**誤り報告フォームルートも併存**：
- contact.htmlで「サイト内容の誤りを報告する」を選択し、1998/320/ソングのキーワードを報告しても進める（上級者向けショートカット）

**ヒント**：
- Night1クリア後のメール「…このサイト…よく読んで…間違ってる…ところがある…ひとつじゃない…見つけたら…教えて…」

## Night3への入口

**方式**：キツネ団長チャットで3つのクイズに正解する

**場所**：キツネ団長チャット（chat/index.html）

**前提**：
- Night2クリア後のメール「ぼくと話そう！」でチャット解放
- Night2クリア後のメール「クイズの準備ができたよ！」で誘導

**仕掛け**：
キツネ団長（子ども番組MCの口調）と軽い会話を3回した後、クイズモードに入る。Night2までの公式サイトで読んだ情報を元に答えるキーワード入力式。

**ウォームアップ会話（3段階）**：
1. 「キミもこの番組のこと調べてるの？」→ 何を言っても自然に返す
2. 「ぼくたちのこと覚えてくれてる人がいるって嬉しいんだ。キミはどのキャラクターが好き？」→ キャラ名に応じた返し
3. 「ところでキミ、サイトのページちゃんと読んでくれた？」→ クイズ導入

**クイズ3問**：

**Q1：「辞めた脚本家の名前」**
- 答え：「渡辺千春」

**Q2：「コーナー間に隠されていたもの」**
- 答え：「ブリッジ映像」

**Q3：「消えた5番目のキャラ」**
- 答え：「ひかりちゃん」

**全問正解後**：
- 「ぼくのこと、もっと知りたい？」「でもね、ここから先は怖いかもしれないよ」→ Night3入口

## Night4への入口

**方式**：前作サイトとの間違い探し → DMでゆうやけさんぽに報告

**場所**：旧サイトアーカイブ（archive/）+ Popin DM

**前提**：
- Night3クリア後にデスクトップに「旧サイト（アーカイブ）」アイコンが出現
- DM Phase1が解放（ゆうやけさんぽとの会話開始）
- DMウォームアップ会話でアーカイブへの誘導あり

**仕掛け**：
1. 旧サイト（archive/）と今作サイト（official/）を見比べる
2. 黒幕が書き換えた箇所（差分）を3つ見つける
3. DMでゆうやけさんぽに差分を報告する（キーワード入力）

**差分3つ**：
1. スタッフ一覧の「人形デザイン ██████████」の行が今作では削除されている
2. 試作キツネの説明が「密かに保管」→「廃棄処分」に書き換えられている
3. ゆめスタジオの設立年が「1987年」→「1988年」に変更されている

**報告方法**：DMでキーワードを伝える
- 「試作きつね」「保管」「廃棄」→「…そうだ…前は保管だったはず…書き換えられてる」
- 「人形デザイン」「名前が消えてる」→「…やっぱり気づいたか」
- 「1987」「設立年」→「…設立年が1年ずれてる…」
- 3つ伝える →「…全部見つけたのか。あなたには全部話す。こっちに来てくれ」→ Night4入口

**ストーリー的な意味**：
- ゆうやけさんぽに調査結果を報告 → 信頼関係が深まる
- エンドの説得に繋がる導線になる

## エンド分岐

**2エンド制（順番固定：エンドB → エンドA）**

### 1周目 → 必ずエンドB（バッドエンド）
- 1周目はDMの説得キーワードが足りない設計
- 「PROCESS STILL RUNNING」「予定通りです」
- Night5セーブポイントに戻れる

### 2周目 → 条件達成でエンドA（真エンド）
- エンドB後にDMのPhase 4が解放される
- 2周目限定キーワード（「吉田」「あかね」「騙されてる」等）で吉田一郎を説得
- 3キーワード以上ヒット → エンドA条件達成
- 吉田一郎がシステムをシャットダウン → あかねのデータ消滅
- あかね「パパ」「ありがとう」→ 全部消える
- 「PROCESS TERMINATED」
