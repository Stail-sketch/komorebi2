# ARG入口ガイド
# こもれびゆうえんち2 - 各Nightへの入り方
# 最終更新：2026-04-02

---

## 全体の流れ

```
PCデスクトップ（index.html）
  ├── ブラウザ → 特番サイト（official/）
  ├── Popin → 架空SNS + DM（twitter/）
  ├── メール → 受信ボックス（mail/）
  └── チャット → キツネ団長チャット（chat/）※Night2クリア後に解放
```

※ チャットは初期非表示。Night2クリア後のメールで「▶チャットを始める」を押すとデスクトップに追加される。

## Night1への入口

**場所**：特番サイト → スタッフページ（official/staff.html）

**仕掛け**：「吉田一郎」の名前を10秒間長押し

**プレイヤーが気づくための違和感（全部さりげない）**：
- 吉田一郎だけフォントの太さが微妙に太い（font-weight: 700 vs 他の通常）
- 行間がほんの少し広い
- ページ読み込み時に0.1秒遅れて表示される
- 表示直後に一瞬チカッと光る
- 30秒ごとに一瞬（0.1秒）消えてまた戻る
- マウスホバーで微妙に文字が揺れる

**長押し中の演出**：
- 画面全体がじわじわ暗くなる（10秒かけてフェードtoブラック）
- 吉田の文字が強く震え始める
- 10秒で完全暗転 → Night1へ遷移
- 途中で離すと暗転がスッと元に戻る

**ヒント**：
- メール初期メッセージ「…離さないで…あの名前を…」

## Night2への入口

**方式**：3ページの「違和感」を見つけてクリック収集 → contact.htmlにグリッチ出現

**場所**：official/photos.html, basic.html, tips.html → contact.html

**仕掛け**：3つの「記憶の断片」を見つけてクリックすると収集される。3つ揃った状態でcontact.htmlを開くとフォームがグリッチしてNight2入口が出現。

**断片の隠し場所（各ページで違和感の種類が異なる）**：

1. **photos.html — キツネ団長の写真が一瞬だけジャンプスケア顔になる**
   - 4〜7秒ごとに80msだけジャンプスケア版の画像に切り替わるサブリミナル演出
   - 他のキャラは普通の写真。キツネ団長だけ「え、今の何？」ってなる
   - クリックで断片1取得

2. **basic.html — 放送回数「315回」が一瞬別の数字に変わる**
   - 3〜5秒ごとに「約0回」「約???回」「約■■■回」にチカッと変わって戻る
   - クリックで断片2取得

3. **tips.html — 一番下に壊れた投稿がある**
   - 他の投稿とフォーマットが違う、半透明の壊れた投稿
   - 「…き…おく…の…かけら…を…あつめ…て…」
   - クリックで断片3取得

**3つ収集後にcontact.htmlへ**：
- フォームがぼやけてグリッチ
- 「記憶の断片が揃いました」パネル出現
- 「記憶の先へ」→ Night2へ遷移

**旧方式（件名に「きおく」入力）も併存**：
- 直接「きおく」と入力しても進める（上級者向けショートカット）

**ヒント**：
- Night1クリア後のメール「…記憶が…散らばっている…3つの…ページに…集めろ…」

## Night3への入口

**方式**：キツネ団長チャットで3つのクイズに正解する

**場所**：キツネ団長チャット（chat/index.html）

**前提**：
- Night2クリア後のメール「ぼくと話そう！」でチャット解放
- Night3クリア後のメール「クイズの準備ができたよ！」で誘導

**仕掛け**：
キツネ団長（子ども番組MCの口調）と軽い会話を3回した後、クイズモードに入る。Night2までの公式サイトで読んだ情報を元に答えるキーワード入力式。

**ウォームアップ会話（3段階）**：
1. 「キミもこの番組のこと調べてるの？」→ 何を言っても自然に返す
2. 「ぼくたちのこと覚えてくれてる人がいるって嬉しいんだ。キミはどのキャラクターが好き？」→ キャラ名に応じた返し
3. 「ところでキミ、サイトのページちゃんと読んでくれた？」→ クイズ導入

**クイズ3問（固有名詞の答え、複数ページの情報を組み合わせて推理）**：

**Q1：「辞めた脚本家の名前」**
```
キツネ団長「この番組でね、自分が書いたものと違うものが放送されてるのに気づいて、
辞めちゃった人がいるんだ。その人の名前、わかるかな？」
```
- 答え：「渡辺千春」
- ヒント元：report_recording.html（脚本家が離脱）+ staff_update.html（渡辺千春＝脚本）+ report_music.html（渡辺氏が台本を保管）
- 難しさ：「台本を書いていた人」だけでは候補が複数（木村洋子も「自分が作ったものと違う」と言っている）。「辞めた」の条件で絞る

**Q2：「コーナー間に隠されていたもの」**
```
キツネ団長「コーナーとコーナーの間に何か挟まってたの、知ってるかな？
脚本家さんは書いてないのに、なぜかそこにあったんだ。あれ、なんて呼ばれてたっけ？」
```
- 答え：「ブリッジ映像」
- ヒント元：kikaku_01.html（企画書に「ブリッジ映像 ※別途指示」）+ report_recording.html or report_music.html（ブリッジ映像への言及）
- 難しさ：「番組と番組のあいだに隠されていた」から企画書とレポートを照合して名称を導く

**Q3：「消えた5番目のキャラ」**
```
キツネ団長「企画書にはね、ぼくたちの名前が5つ書いてあったんだ。
でも放送されたのは4つだけ。消えちゃった5番目のおともだち、名前わかるかな？」
```
- 答え：「ひかりちゃん」
- ヒント元：kikaku_02.html（キャラクター設定資料・初期案に5体目「ひかりちゃん」）
- 難しさ：kikaku_02.htmlを読んでいないと名前が分からない

**全問正解後**：
```
キツネ団長「全問正解！キミはすごいね！」
「……」
「……ねえ」
「ぼくのこと、もっと知りたい？」
「でもね、ここから先は怖いかもしれないよ」
「それでも、来てくれる？」
  → [行く] ← Night3入口
```

## Night4への入口

**方式**：前作サイトとの間違い探し → DMでゆうやけさんぽに報告

**場所**：旧サイトアーカイブ（archive/）+ Popin DM

**前提**：
- Night3クリア後にデスクトップに「旧サイト（アーカイブ）」アイコンが出現
- メール「…古い資料が見つかった…」が届く
- 前作official/から必要なページをarchive/にコピーして配置

**仕掛け**：
1. 旧サイト（アーカイブ）と今作サイトを見比べる
2. 黒幕が書き換えた箇所（差分）を見つける
3. DMでゆうやけさんぽに差分を報告する（キーワード入力）

**差分3つ**：
1. スタッフの名前が1人消えている
2. 試作きつねの説明が「保管」→「廃棄」に変わっている
3. ある日付が1年ズレている

**報告方法**：DMでキーワードを伝える
- 例：「試作きつね」→「…そうだ…前は保管だったはず…」
- 例：「名前が消えてる」→「…やっぱり気づいたか…」
- 3つ伝える →「…あなたには全部話す。こっちに来てくれ」→ Night4入口

**ストーリー的な意味**：
- ゆうやけさんぽに調査結果を報告 → 信頼関係が深まる
- エンドの説得に繋がる導線になる

## Night5への入口

**場所**：複数ページにまたがるURL組み立てパズル

**仕掛け**：全ページに散らばったヒントを集めて `/night5/199709/` というURLを組み立てる

**ヒントの場所**：
1. **最終調査結果（official/final_report.html）**
   - ドキュメント参照番号として「doc-ref:199」が極小テキストで表示

2. **大量の情報提供（official/flood.html）**
   - ガーブルエントリの中に「ref::709::ERR_CANNOT_RESOLVE」

3. **緊急情報提供（official/emergency.html）**
   - HTMLコメント：`<!-- 全ての断片を...つなげろ.../night5/の先に...数字が待っている... -->`
   - ほぼ見えない固定テキスト：「全ての断片を...つなげろ.../night5/の先に...」

**199 + 709 = /night5/199709/**

**遷移**：
- `/night5/199709/index.html` にアクセス
- 「…見つけた…」というテキストが表示
- 2秒後にNight5ゲーム本体へリダイレクト

## Night6への入口

**方式**：メールトリガー（プレイヤーが自分のタイミングで進める）

**場所**：メール受信ボックス

**前提**：Night5クリア後

**仕掛け**：
1. Night5クリア → 特番サイトに戻る
2. サイトを自由に探索できる（最後の証拠集め・DM会話）
3. メールに差出人不明の新着「準備はできましたか」が届いている
4. メール内の「開始」リンクをクリック → Night6へ遷移

**崩壊演出**（Night5クリアから60秒後に自動発生）：
- Stage1：画面が揺れ始める
- Stage2：テキストが文字化け
- Stage3：完全崩壊
- Stage4：黒幕の語りかけ「来い」→ Night6リンク

※ 崩壊演出とメールトリガーの2つのルートでNight6に入れる

## エンド分岐

**2エンド制（順番固定：エンドB → エンドA）**

### 1周目 → 必ずエンドB（バッドエンド）
- 1周目はDMの説得キーワードが足りない設計
- 黒幕のログ表示 → K-059転送 → 吉田一郎の裏切りバレ
- 「PROCESS STILL RUNNING」「予定通りです」
- Night5セーブポイントに戻れる

### 2周目 → 条件達成でエンドA（真エンド）
- エンドB後にDMのPhase 4が解放される
- 2周目限定キーワード（「吉田」「あかね」「騙されてる」等）で吉田一郎を説得
- 3キーワード以上ヒット → エンドA条件達成
- 吉田一郎がシステムをシャットダウン → あかねのデータ消滅
- あかね「パパ」「ありがとう」→ 全部消える
- 「PROCESS TERMINATED」
- おわり

### 分岐判定
```
Night6クリア時:
  ending_b_seen === true && persuasion_keys >= 3 → エンドA
  それ以外 → エンドB
```
