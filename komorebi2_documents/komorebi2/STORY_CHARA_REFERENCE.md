## 作品概要

前作「木漏れ日遊園地」の直接続編。FNAFライクな監視カメラホラーゲーム＋ARG。
HTML/CSS/JSのみでブラウザゲームとして実装。GitHub Pagesで公開。
**前作プレイ済み前提**（新規プレイヤー向けの配慮なし）。

## 世界観

### 前作（木漏れ日遊園地）の概要
1991〜1997年に放送された子ども番組「木漏れ日遊園地」。
楽しい番組の裏で、子どもの感情反応を収集する実験が行われていた。
1997年秋、試作きつねのデータが放送波に混入→番組終了。
制作会社「ゆめスタジオプロダクション」は消滅。

前作エンドで「PROCESS STILL RUNNING」「K-059」「予定通りです」というメッセージが残された。

### 次回作（2026年）の状況
黒幕（データ生命体）がAIを使って情報番組を作り、現代に復活。
「木漏れ日遊園地の関係者・被験者を探す」尋ね人系生放送特番という体裁。
プレイヤー（一般人）がこの番組を発見し調査を始めるところから物語が始まる。

## テーマ・感情設計

**プレイヤーに感じてほしい感情**：「騙されたーーー、でも悲しーーー」

**終盤の逆転**
- 前作で「黒幕だと思っていた白い目の存在」→実は最大の被害者（獣人＝吉田一郎の娘）
- 「K-059」→実はプレイヤー自身のこと
- 「予定通りです」→プレイヤーが調査しに来ること自体が黒幕の計画だった

## 登場キャラクター

### 黒幕（██████████）

**正体**：データ生命体。1986年に実験システム構築時に偶発的に発生。
前作では書類上の架空の人物名として黒塗りされていた存在。前作プレイヤーにはほぼ認識されていない。

**次回作での目的**
- 大人の感情・情報・反応を収集してさらに進化
- K-059（プレイヤー）を器にすることが最終目標

**手法**
- AIが生成した情報番組を作りプレイヤーを誘導
- 吉田一郎を操って物理的な作業をさせる
- プレイヤーの調査行動全部が計画通り（デスノートのキラ的な「全部読まれてた感」）
- 姿・声は出さず行動の痕跡だけが積み重なっていく
- Night5クリア後に初めてプレイヤーに直接語りかける
- Night6中にランダムでシャッターを勝手に開く

**Night5クリア後の台詞**
「ようやく来たか」「ずっと待っていた」「お前のことは最初から知っていた」「予定通りだ」「さあ…お前を取り込んでやる」

### 吉田一郎

**前作での立ち位置**：セット設計担当。前作プレイヤーには「大体こいつが悪い」と思われていたキャラ。

**次回作での役割**
- 1990年に娘が行方不明になった（実際は獣人化していたがゆめスタジオに隠蔽された）
- 2026年に黒幕から「娘を取り戻せる」と接触される
- 藁にもすがる思いで番組制作に協力
- 人形の調達・修復・新キャラ制作・スタジオ設計を担当
- 番組サイトの管理権限を持ち、娘を探す情報をこっそり混ぜ込んでいる
- 自分が騙されていることに気づいていない
- 娘＝獣人であることを知らない

**架空Twitterアカウント名**：吉さん
- 一見普通の視聴者アカウント
- Nightが進むにつれて娘を探している痕跡が滲み出てくる
- でも直接的には言わない・「よく読んだら気づく」レベル

| タイミング | ツイート |
|-----------|---------|
| Night1後 | 「久しぶりにテレビつけたら懐かしい顔が映ってた」 |
| Night2後 | 「仕事辞めてもう何年経つんだろ。あの頃は毎日必死だったな」 |
| Night3後 | 「春になると散歩しながらいろいろ考える。毎年ね」 |
| Night4後 | 「この番組見てて、あの頃のことを思い出した人いるんじゃないかな。俺だけじゃないはず」 |
| Night5後 | 「連絡、来るといいな」 |

### ゼロ号被験者（獣人）

**正体**：吉田一郎の娘。1990年時点で3〜5歳の女の子。

**経緯**
- 黒幕が最初から「器」として狙っていた（K-059の原型・失敗作）
- 1990年のテスト収録で意識を試作きつねに吸収される
- 体が獣人化→ゆめスタジオが隠蔽
- 吉田一郎には「娘が行方不明」とだけ伝えられた

**前作での扱い**：白い目の存在として登場→プレイヤーは黒幕だと思っている

**次回作での扱い**
- 名前は終盤のARGで判明（それまでは番号のみ）
- プレイヤーが正しい名前を入力することで救済（この世から消す＝苦しみから解放）
- エンドAのみ救済可能

|--------|------|---------|------------|------|

### 新キャラ5体（思念体）

吉田一郎が作った人形に黒幕が感情データを注入。夜間に思念体として動き回る。
**プレイヤーにだけ見える**（黒幕がK-059であるプレイヤーの認識に干渉しているため）。
他の視聴者には普通のスタジオ映像に見えている。

| Night | 名前 | 動物 | 収集する感情 | 操作 | 性質 |
|-------|------|------|------------|------|------|
| Night1 | くるる | リス | 好奇心 | カメラで監視→ドアで撃退 | 王道（カメラ監視で移動が遅くなる） |
| Night2 | まだら | カメレオン | 不信感 | うっすら見つける→ドアで撃退 | ステルス（opacity低い、注意深く見ないと気づかない） |
| Night3 | かすみ | シカ | 郷愁 | 中央モニターに出現→受け取るか判断 | 選択＋代償（電力回復するがカメラ10秒ノイズ。受け取らなくてもOK） |
| Night4 | アラネ | クモ | 執着 | ベントカメラで長押し→巣ゲージ補充 | リソース管理（巣ゲージが常に減少。0%で突撃。長押し中は他操作不可） |
| Night5 | よわり | ヒツジ | 罪悪感 | 中央モニターに映り込む→ドラッグで画面外に追い出す | お邪魔キャラ（直接殺さないがカメラ映像を塞ぐ。ドラッグ中カーソル拘束） |

**Nightごとの登場キャラ数（累積）**：
- Night1: くるるのみ
- Night2: くるる + まだら
- Night3: くるる + まだら + かすみ
- Night4: くるる + まだら + かすみ + アラネ
- Night5: くるる + まだら + かすみ + アラネ + よわり

**見た目**：半透明・ぼんやり。危険が近づくほど不透明になる。

### キツネ団長（ARGパート）

FNAFパート以外での役割。味方としてプレイヤーを助けようとする。

**登場方法**：架空Gmail風メールページ
- 最初からプレイヤーのメールボックスにメールが届いている（なぜ届いているか自体が謎）
- Nightクリアごとに新しいメールが届く
- Night3クリア後のメールにチャットページへのURLが貼られている
- 断片的・不完全な情報しか伝えられない（黒幕の支配下のため）
- 送信者名は最初不明→ARGを進めると「キツネ団長だ」と気づく

**チャットページ**：MSNメッセンジャー風UI・キーワード検知の固定返答・タイピング演出あり

## ストーリーの流れ

### 序盤（Night1前）
1. 特番サイトを発見・アクセス
2. 開いた瞬間に微妙な演出（黒幕がプレイヤーを検知）
3. 普通の特番サイトとして読み込んでいく
4. キツネ団長から謎のメールが届いている
5. スタッフクレジットの「吉田一郎」を長押し→Night1へ

### 中盤（Night1〜5）
- Nightクリアごとに特番サイトに新ページが追加される
- 吉田一郎（吉さん）の正体が少しずつ見えてくる
- 黒幕（かあ博士風アカウント）がARGを妨害する
- うっきち・ぽたまるが架空Twitter・メールで不気味な存在感を出す
- Night3以降、キツネ団長チャットが使えるようになる
- Night4で前作公式サイトが出てくる（前作プレイヤーへのサプライズ）

### 終盤（Night5クリア後）
1. Night5クリア→シンプルなクリア表示
2. サイトに戻ると1分間は普通に見れる（最後の証拠集めチャンス）
3. 1分後→全サイトが段階的に崩壊していく
4. 黒幕が初めてプレイヤーに直接語りかける
5. 「来い」→Night6へのリンク

### Night6・エンド
- 新5体＋旧4体全員＋黒幕の攻撃（シャッターが勝手に開く）
- 証拠の数でエンドが分岐
  - エンドA（証拠15個以上）：名前入力→獣人救済→黒幕消滅→感動エピローグ
  - エンドB（証拠8〜14個）：黒幕消滅・獣人は救えない→後味の悪いエピローグ
  - エンドC（証拠7個以下）：K-059完成→壊滅→「予定通りです」再び

## ARG構造の概要

**使用する場所**
- 特番公式サイト（メイン）
- 架空Twitter（雰囲気・伏線・Night6で暴走）
- 架空Gmailメール（キツネ団長からのヒント）
- キツネ団長チャット（Night3以降）
- 前作公式サイト（Night4でサプライズ登場）

**Nightごとの謎解き**
| Night | 謎解きの方式 |
|-------|------------|
| Night1 | スタッフクレジットの「吉田一郎」を長押し |
| Night2 | 3ページの変な部分を見つけて合言葉→フォームに入力 |
| Night3 | 調査記録の矛盾3つをチャットで報告→ヒントが集まる |
| Night4 | 前作サイトと今作サイトを見比べて差分を発見→メールと組み合わせ |
| Night5 | 全ページに散らばったヒントを集めてURL組み立て |
